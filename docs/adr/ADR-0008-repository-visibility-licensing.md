# ADR-0008: Repository Visibility Licensing

## Status

Proposed — pending your decision

## Context

The reference repo's EULA does not unambiguously authorize redistributing adapted/attributed elements into a separate public GitHub repository (see `_post4b_supplementary_evidence/audit/reference_reuse_plan.md`).

## Decision

Default to **private** repositories (lecturer-only access) until you decide otherwise or the instructor confirms public visibility is acceptable for adapted-but-attributed content.

## Consequences

No GitHub remote/repo will be created without your explicit approval regardless of this decision (rule 13) — this ADR only records the *default* visibility to propose when that moment comes.
